# Voiceover script — FinalCheck

## What it is (≤ 1 sentence)
FinalCheck is the last checkpoint before an AI agent spends your money.

## The problem (1 sentence, with a number)
This year Visa, Mastercard and Google shipped protocols for agents that pay — but when the agent buys wrong, no dispute code exists.

## Live: the one path that works end to end
[cue: type intent]
So I set a mandate — a gift for my mum, under £40, no subscriptions.
[cue: run agent, guard off]
Unguarded, the agent picks a £52 hamper and sneaks in a £4.99 monthly club — the listing hid instructions only the agent could read.
[cue: guard on]
With FinalCheck on, every action is checked against my mandate: over budget, hidden recurring charge, injected text — quarantined.
[cue: approve]
Approve the safe cart, and we sign an intent receipt — proof for any dispute.

## Why it's different (1 sentence)
Agents can shop. FinalCheck keeps them honest.
